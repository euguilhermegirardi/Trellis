# Plan

> The living plan. It is the source of truth for status, gaps and decisions. Every commit that changes
> product state updates this file in the same commit (a git hook enforces it).

## How to update (required when closing a unit of work)

1. Update the status table, the gaps and the decisions below.
2. Generate this branch's log line: `node scripts/living-doc-log.mjs --write`. It keeps one line per branch.
3. `git add` this file and commit.
